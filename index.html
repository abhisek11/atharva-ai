How Fragments Travel Over Home Internet Without Losing Accuracy

Every worker trains for LOCAL_STEPS = 200 locally, computes Δ = θ_local − θ_global + residual, transmits only the top 1% largest coordinates in fp16, and saves the dropped 99% into self.residual for the next round.

01 Lease Fragment & Sync Weights
GET /work/{worker_id}

Coordinator assigns an idempotent data/model fragment with a 10-minute Redis ZSET lease (jobs:leased). If a node disconnects, its lease expires and re-queues automatically.

02 Heterogeneous Inner Loop
LOCAL_STEPS = 200

Workers execute 200 local AdamW steps on CUDA GPU, TPU, or system RAM without waiting for peers, then compute the parameter trajectory delta against global weights.

03 Top-1% Sparsification + Residual Buffer
TOPK_FRACTION = 0.01

compress_state_delta() packs the top 1% magnitudes in little-endian binary + fp16 (~100× smaller). Dropped coordinates accumulate in self.residual so zero gradient information is lost.

04 Windowed Aggregation → Load on 1 Machine
model_v{N+1}.pt

Every 60s, aggregator.py drains all arrived deltas, weights them by steps_completed, applies OUTER_LR = 0.7, and writes a single unified PyTorch checkpoint ready to load on any machine.

One-Command Support Doctor

Run python cli/doctor.py on any coordinator or worker to generate a secret-redacted atharva-doctor.tar.gz containing GPU inventory, Redis queue depths, and Docker logs.

St

Staleness-Guarded Async Windows

Workers never block on stragglers. Deltas within STALE_VERSION_TOLERANCE = 1 are weighted-averaged in the next 60s window; overly stale leases safely re-queue.
